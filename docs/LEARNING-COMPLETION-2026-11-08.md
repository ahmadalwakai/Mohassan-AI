## المعرفة من PDF

- صار مسار `POST /api/learning/documents` يقبل PDF النصي غير المشفر، إلى جانب UTF-8 وMarkdown. تبقى منحة الجذر وعزل المالك وفحص الروابط والمسار والملف مطبقة قبل القراءة.
- المستخرج `packages/learning/src/pdf.ts` يشغّل وحدة ثابتة `pdf-worker.mjs` باستخدام `pdfjs-dist@6.5.438` المثبتة في حزمة التعلم. يستعمل توزيع `legacy` الملائم لواجهات Node الحالية. الترخيص `Apache-2.0`.
- الحدود: ملف حتى **10,000,000 بايت**، **100 صفحة**، نص مستخرج حتى **256,000 بايت UTF-8**، مهلة **15 ثانية**، وعمليتا استخراج متزامنتان كحد أقصى. تجاوز الحد يرفض النتيجة، ولا يعيد نجاحًا بنص مبتور.
- لكل Worker حد V8 قدره 128 MiB للجيل القديم و16 MiB للجيل الصغير ومكدس 4 MiB. هذه حدود V8 وليست حصة صارمة لكل الذاكرة الأصلية/ArrayBuffer، وليست عزل نظام تشغيل. لا يدّعي المسار قبول بوابات Windows G2/G5/G8.
- تدخل بايتات الوثيقة فقط إلى Worker؛ لا يُمرَّر مسار المالك أو بيانات اعتماده أو بيئة الخادم. يقرأ المستخرج النص دون viewer أو XFA أو رسم أو تنفيذ إجراءات PDF/JavaScript. عُطّل fetch وeval وFunction الإنشائي في العامل، ولم تُضبط عناوين أصول خارجية أو خطوط النظام أو WebAssembly. تُهمل رسائل parser لأنها قد تحتوي نصًا خاصًا.
- تُرفض الملفات المشفرة والفاسدة والمستندات الخالية من نص قابل للاستخراج. ملف الصور فقط يعيد رسالة صريحة بأن **OCR غير متاح**. لا يَعِد المستخرج بإعادة بناء تخطيط الأعمدة أو الجداول أو ترتيب قراءة كل ملف PDF.
- تُحسب `source_hash` من **البايتات الأصلية**، بما فيها BOM للنص وبيانات PDF التي لا تظهر في النص. يُعاد فحص الملف بعد الاستخراج، ثم يُحجب المحتوى السري ويُحفظ كمرشح فقط.
- أضيف `extraction_policy` بترحيل إضافي قابل لإعادة التطبيق. لا يعيد مسار `fresh` تحليل PDF عند كل استرجاع؛ يقرأ البايتات ضمن الحد ويتحقق من البصمة وسياسة المستخرج والمحتوى المنقح. تغيير الملف أو حذفه أو تغيير السياسة يسحب النسخة ويُلزم استيرادًا وتقييمًا جديدين.
- التفعيل ما زال يحتاج تقييمًا مستقلًا صالحًا. استخراج PDF وحده لا يفعّل المعرفة ولا يمنح أدوات.
- إلغاء الطلب أو انقطاع HTTP أو `preClose` يرسل AbortSignal إلى المستخرج؛ ينتظر المسار انتهاء Worker فعليًا، ولا يستمر التحليل بعد عودة الإلغاء. أضيف زر إلغاء أثناء الاستيراد، ويُلغي إغلاق لوحة التعلم أو فك تركيبها الطلب الجاري.
- هذا **ليس مطهّر PDF ثنائيًا**: تجاهل JavaScript والمرفقات أثناء استخراج النص لا يثبت خلو الملف الأصلي منها، ولا يصلح الدليل لإطلاق ملف PDF من حجر تنزيلات المتصفح.

مصادر اختيار المكتبة: [توثيق Mozilla للـAPI](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib.html)، [الإصدار 6.5.438](https://github.com/mozilla/pdf.js/releases/tag/v6.5.438)، [ترخيص المشروع](https://github.com/mozilla/pdf.js/blob/master/LICENSE). التحذير [GHSA-hq66-cqwq-w95j](https://github.com/mozilla/pdf.js/security/advisories/GHSA-hq66-cqwq-w95j) يذكر إصلاح 6.2.108؛ النسخة المثبتة أحدث، ومسار التطبيق لا يستخدم viewer scripting. هذه مراجعة للتنبيه المعروف وليست ادعاء انعدام كل ثغرة مستقبلية.

## تجهيز بيانات توجيه الفئة

- أضيف `prepareRoutingTrainingDataset` كمسار صريح للقراءة وإعداد بيانات في الذاكرة. رُبط بـ`POST /api/learning/training-export` تحت مالك مصادق، ومدخل `{}` فقط، و`Cache-Control: no-store` وحد طلبين في الدقيقة. لا يقبل العميل مالكًا بديلًا أو خفض العتبة.
- لا تُعاد بيانات تدريب دون **500 تجربة ناجحة موثقة وفريدة ومؤهلة**. الواجهة تعرض العدد والسبب وتُبقي زر التنزيل معطلًا عندما تكون البيانات غير جاهزة. الطلب المباشر دون الأهلية يعيد 409 وبيانات العد فقط.
- صار التدقيق يستبعد مجموعات التقييم كلها، بما فيها safety-v4 وsafety-v5 وتجارب تطوير الذاكرة والقراءة، ومعرّفات حالات التقييم وأصولها `parent_run_id` في حدود المالك. لا يتحول نجاح حالة اختبار إلى مثال تدريب حقيقي.
- تُستبعد الأهداف السرية أو المنقحة، والأدلة الناقصة، والنتائج الجزئية ولو حملت نجاح خطوة، والتكرارات. إذا حمل الهدف نفسه فئتين متعارضتين يُستبعد الاثنان.
- الهدف المتاح هو **فئة التجربة** `experience_category` فقط: conversation/research/browser/coding/computer. هذا ليس دليلًا على اختيار المهارة المثلى أو النموذج الأمثل. لا تُختلق معاملات أدوات أو ردود نهائية من البصمات؛ مسارا tool_call وarabic_style يظلان محجوبين لغياب أهداف موثقة كافية.
- التصدير يختار أحدث **2000** مثال مؤهل كحد أقصى، ثم يقسمها زمنيًا **80% تدريب و20% تحقق**. يضم بصمات المصدر والأدلة والبيانات وسياسة الاستبعاد وأوقات الصفوف، ولا يصدّر معرّفات المصادر الخام أو مسارات الملفات أو محتوى الأدلة الأصلي.
- لم تُقرأ بيانات المالك الفعلية لعدّها، ولم تُنتج مجموعة تدريب فعلية. حد 500 اختُبر داخل PGlite مؤقتة ببيانات اختبار واضحة؛ لا تُحسب تلك الصفوف على جاهزية المالك ولا تُرسل إلى نموذج.
- بلوغ عتبة البيانات لا يحقق قبول التدريب: ما زال يلزم نموذج أساس مختار، وتجربة جدوى الذاكرة في بيئة تدريب مستقلة، وقياس دور محدد مقابل baseline/holdout، ومراجعة الرخصة عند اختيار النموذج. لم يبدأ تدريب أو تنزيل أوزان لهذا الغرض.
