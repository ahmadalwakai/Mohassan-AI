# المرحلة الخامسة — شريحة الاستوديو الثابت

تاريخ التنفيذ: 2026-11-04. المنفذ استوديو لملفات HTML وCSS الصغيرة: معاينة، تحديد عنصر وربطه بمصدره، تحرير النص والتنسيق، حفظ نسخة مراجعة في SQL، والتراجع والمقارنة مع الأصل. لا يعني ذلك اكتمال الاستوديو العام المقترح في الخطة.

هذه وثيقة الشريحة الثابتة الأولى. التوسعة التالية منفذة في [PHASE-5-REACT.md](PHASE-5-REACT.md): عرض أولي لمكوّنات React وصفحة Next بسيطة مع layout داخل AppContainer، مع تعديل JSX/TSX وحفظ أثر المعاينة. يظل تشغيل Next الكامل وربط التعديل باللغة الطبيعية وتحويل الصور إلى كود خارج الشريحة الحالية.

## الرحلة الحالية

1. من «الاستوديو البصري» أنشئ مشروع التجربة، أو استورد مجلد HTML/CSS داخل `CODING_ALLOWED_ROOTS` مع ملف بداية مثل `index.html`. لا يتطلب المجلد Git أو Node أو حزمًا خارجية.
2. يحتفظ الخادم بنسخة أصلية ونسخة حالية في قاعدة البيانات؛ يقرأ المجلد عند الاستيراد فقط. لا يكتب إلى ملفاته أو Git، ولا يشغل build أو خادم مشروع أو JavaScript منه.
3. تعمل المعاينة من HTML يعيد المحرك بناءه بقائمة عناصر وسمات مسموحة. تعرض تحذيرًا عند حجب محتوى غير مدعوم، ولا تعد نسخة مطابقة لكل سلوك الصفحة الأصلية.
4. يرسل النقر معرف عنصر في إصدار معين. يربطه الخادم وواجهة المراجع بملف البداية ورقم السطر من محلل HTML ذي مواقع مصدر؛ العنصر الذي يحتوي أبناءً لا يقبل استبدال نصه كاملًا. يمكن تعديل تنسيقه أو اختيار عنصر نصي أدق.
5. يحرر المستخدم النص أو اللون أو الخلفية أو حجم الخط، ثم يحفظ صراحةً. تعديلات المعاينة المؤقتة ليست ملفات محفوظة. لا ينشأ طلب نموذج أو مهمة عامل أو طلب موافقة إضافي لهذا التحرير المباشر لنسخة المراجعة.
6. الحفظ يعيد اشتقاق ربط العنصر من المصدر الحالي، ويرفض إصدارًا قديمًا بـ409. تعرض النسخة الجديدة والمعاينة الأصلية وفرق المصدر للمراجعة. التراجع يستعيد آخر نسخة محفوظة ويولد إصدارًا جديدًا؛ لا يعيد صلاحية طلب قديم.

## الحدود الحالية

- حتى 20 جلسة محفوظة للمالك، و40 ملفًا HTML/CSS لكل جلسة، و64,000 بايت لكل ملف، و128,000 بايت إجمالًا. ملفات حساسة وروابط رمزية وjunctions وhardlinks وملفات ثنائية أو اعتماديات خارج الشريحة مرفوضة.
- حتى 1,000 عنصر قابل للربط؛ عمق HTML وعدد عقده محدودان. الربط يخص HTML المحلل من ملف البداية، ولا يدعي ربط مكونات React أو الشيفرة التي تولد DOM ديناميكيًا.
- تعديل النص المباشر حتى4,000 حرف، واللونان بصيغة HEX من ست خانات، وحجم الخط عدد صحيح بين 8 و96 بكسل. لا حقل لمسار كتابة أو موضع نص حر أو أوامر نظام.
- روابط CSS المحلية تؤخذ من ملفات النسخة فقط. لا موارد شبكة أو صور أو خطوط خارجية، ولا تنفيذ scripts أو event handlers أو إرسال forms أو تنقل روابط داخل المعاينة.
- سجل التراجع يحتفظ بآخر 20 نسخة؛ عند زيادة العدد تحذف أقدم نسخة من سجل التراجع فقط، وتبقى النسخة الأصلية. لا redo أو حذف جلسة أو تنظيف احتفاظ تلقائي حاليًا. طلب إنشاء التجربة مرة أخرى يعيد جلسة التجربة المحفوظة وتعديلات المستخدم فيها.
- النص الأصلي يبقى في نسخة المراجعة، بما فيه محتوى تحجبه المعاينة. الحجب يخص العرض الآمن، وليس تنقية ملف المصدر الأصلي أو ضمان سلامته عند تشغيله خارج الاستوديو.

## حد الثقة للمعاينة

الشريحة تستخدم `iframe srcDoc` مع `sandbox="allow-scripts"` دون `allow-same-origin` أو أذونات نماذج/تنقل/نوافذ. لها أصل opaque؛ لا تتشارك أصل الواجهة أو cookies أو أسرار الخدمة. السكربت الوحيد المسموح به في المستند المعاد بناؤه هو جسر التحديد الموثوق ذو nonce؛ CSP يمنع الشبكة والإطارات والكائنات والموارد الخارجية. لا ينفذ كود مشروع على المضيف أو داخل الصفحة.

رسالة التحديد عقد صارم `{type:'mohassan:studio:select',nonce,revision,elementId,styles?}`. التنسيق الاختياري قيم محسوبة محدودة للألوان وحجم الخط فقط، وليس ملفًا أو موضع كتابة أو صلاحية. تقبل الواجهة `event.origin === 'null'` **لهذا الإطار فقط** مع تطابق `event.source` مع نافذته، والـnonce العشوائي من آخر معاينة، وإصدارها، وschema الرسالة، ووجود العنصر في خريطة الخادم. لا يصبح أصل `null` مسموحًا على API أو CORS أو بقية نوافذ المتصفح.

يسمح هذا الجسر المحدود بـ`postMessage` إلى `'*'` بسبب الأصل opaque؛ لا تحمل الرسائل cookies أو محتوى ملفات أو أسرارًا أو صلاحية كتابة أو طلب API حرًا. الـnonce يتغير عند جلب مستند المعاينة. إعادة الرسالة قد تعيد اختيار العنصر نفسه فقط؛ الحفظ فعل منفصل مصادق يملك نسخة محددة ويعيد اشتقاق المصدر. إرسال معرف عنصر من صفحة أو إطار آخر لا يمنح صلاحية حفظ.

كل API يحتاج جلسة المالك والسر الداخلي من وكيل Next، ويحتاج POST أيضًا Origin الموثوق. لا تكشف قراءة جلسة غير مملوكة وجودها؛ تعيد404. التغييرات تتم تحت قفل صف SQL ومقارنة revision، وتولد revision جديدًا حتى عند استعادة المحتوى نفسه بالتراجع.

## التخزين والتحقق

الترحيل `005_visual_studio` يضيف `studio_sessions`. يحفظ `base_snapshot` و`current_snapshot` و`undo_history` في JSONB، مع هوية المالك ومسار الاستيراد الاختياري والإصدار والأوقات. إنشاء الجلسات يقفل صف المالك لضبط حد العشرين بين العمال؛ الحفظ والتراجع يقفلان الجلسة نفسها. لا توجد معاملات SQL مفتوحة أثناء قراءة المجلد أو تشغيل نموذج أو مشروع.

تغطي `tests/studio-control.test.ts` الملكية، والتخزين وإعادة قراءة الحالة، والحفظ والمعاينة الأصلية، والتراجع، وتغير nonce، ورفض النسخ القديمة بعد التراجع، ورفض المعرفات والحقول المزورة، وتزامن محاولتي حفظ، وحد سجل التراجع. اختبارات `packages/studio/src/studio.test.ts` تغطي التحليل وربط المصدر وتطبيق التعديلات وحجب المحتوى وحدود الاستيراد. يسجل `IMPLEMENTATION-STATUS.md` نتيجة التجميع واختبار المتصفح النهائي؛ نجاح حفظ HTML لا يوصف بأنه نجاح اختبارات كود المشروع، إذ لا يشغله الاستوديو أصلًا.

## ما يتبقى من المرحلة الخامسة

تشغيل React/Next والأطر والمشاريع الكبيرة داخل بيئة عزل مناسبة؛ ربط sourcemaps للمكونات الديناميكية؛ توصيل التغيير الموصوف باللغة إلى محرك البرمجة وموافقاته وworktrees واختباراته؛ screenshots مضبوطة وvisual diff آلي؛ Screenshot-to-code؛ استعادة وتسليم ودمج ونشر بصلاحيات مستقلة. مقارنة نسختين ثابتتين في الاستوديو الحالي ليست فحصًا بصريًا آليًا أو تحققًا من تطبيق يعمل.
