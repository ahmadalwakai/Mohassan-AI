# المرحلة الخامسة — معاينة مكوّنات React المعزولة

تاريخ التنفيذ: 2026-11-04. هذه التوسعة تعرض الناتج الأولي الحقيقي لمكوّنات React الصغيرة داخل الاستوديو، مع ربط العناصر بملفات JSX/TSX وتحرير نسخة المراجعة. تدعم أيضًا صفحة Next بسيطة مع layout مجاور بوصفهما مكوّنات React. لا تشمل هذه الشريحة خادم Next ومساراته وخدماته أو تفاعلات المتصفح.

## مسار المعاينة

1. تُقرأ ملفات المصدر من مجلد مصرح به إلى نسخة محدودة مستقلة. يفحص المحلل TypeScript بنية JSX ويعطي العناصر الأصلية معرّفات مرتبطة بالملف والسطر والموضع. لا يُستورد مكوّن المشروع داخل عملية الخدمة.
2. يضيف المحلل سمة مصدر محجوزة بعد بقية السمات؛ لا تستطيع سمات spread استبدال المعرّف الذي يولده المحلل. الربط مرجع إلى المصدر الحالي، وليس مسارًا أو موضع كتابة يختاره المتصفح.
3. يجمع esbuild الملفات من نظام ملفات افتراضي يضم نسخة المراجعة فقط. يسمح بحواف الاستيراد المحلية وReact وJSX runtime الموثوق المثبت مع التطبيق. لا يقرأ إعدادات بناء المشروع ولا يشغل plugins أو npm scripts أو تثبيت حزم منه. ترفض الاستيرادات غير المدعومة برسالة واضحة.
4. ينتج التجميع حزمة CommonJS واحدة تتضمن React وReactDOMServer الموثوقين. تُرسل مع مشغّل `node:test` وملف `package.json` ثابت إلى AppContainer الحالي. يحصر ملف package الموثوق بحث Node داخل نسخة التشغيل؛ لا تُنسخ تعليمات package المشروع إلى مشغّل العزل.
5. ينفذ المشغّل `renderToStaticMarkup` داخل AppContainer فقط. تعمل hooks ذات الحالة الابتدائية، ويستخدم layout المجاور عند وجوده في صفحة Next. المصدر للقراءة فقط، وTEMP مستقل، والشبكة ممنوعة، وحدود العملية والذاكرة والوقت قائمة.
6. يعيد المشغّل سجلًا واحدًا محدودًا يحمل HTML بترميز base64، مع إيصال نظام العزل وبصمة ملفات التشغيل. يتحقق الخادم من المزوّد والبصمة والنجاح والمهلة ودليل العزل قبل قبول الناتج.
7. يظل HTML بيانات غير موثوقة. يعاد بناؤه عبر قائمة سماح الاستوديو الثابت وCSP، وتُحجب scripts والسمات التنفيذية والموارد الخارجية. الإطار المعروض لا يشغل JavaScript المشروع.
8. يحفظ الخادم أثر العرض مع بصمة المصدر. عرض المعاينة المحفوظة أو الأصلية يولد nonce جديدًا من الأثر المحفوظ، ولا يعيد تشغيل المشروع عبر GET. الحفظ يعيد التحقق من revision قبل اعتماد نسخة جديدة؛ فشل العرض يبقي النسخة السابقة قابلة للعرض.

## ربط العنصر وتحريره

تعتمد خريطة العرض على عناصر JSX التي ربطها المحلل، والمعرّفات المعروفة الفريدة الموجودة في الناتج. العنصر المكرر في قائمة ديناميكية، أو الناتج غير المطابق لخريطة المصدر، لا يحصل على ربط تحرير قابل للتخمين. يتطلب تعديل النص نصًا مباشرًا معروفًا من المصدر وتطابقه مع النص المعروض؛ التعبيرات الديناميكية ليست هدفًا لاستبدال النص مباشرةً.

تحرير النص يطبق رقعة على موضع JSX المحدد، مع ترميز النص كبيانات؛ لا يحوله إلى تعبير JavaScript ينفذ إدخال المستخدم. تحرير التنسيق يقبل خصائص اللون والخلفية وحجم الخط المحدودة فقط. التنسيق الديناميكي أو spread غير القابل لرقعة موثوقة يظهر بحدوده بدل الكتابة فوق تعبيرات المشروع. تبقى مراجعة الملكية وإصدار المصدر على الخادم ضرورية لكل حفظ.

## حدود التشغيل

- نفس حدود نسخة المصدر: حتى40 ملفًا، و64000 بايت لكل ملف، و128000 بايت إجمالًا. تجمع CSS العامة المحفوظة في نسخة المعاينة؛ CSS Modules والأصول الثنائية غير مدعومة.
- يستخدم العرض نسخ React وReactDOM المثبتة والموثوقة مع التطبيق. حقول الاعتماديات في package المشروع بيانات وصفية؛ لا تمنح إذن تحميل اعتماديات إضافية.
- يسمح التجميع بحزمة حتى480000 بايت، وتبقى دفعة التشغيل كاملة ضمن حد512KiB الحالي للعزل. لا يزداد حد العمليات أو صلاحية الشبكة لهذا العرض.
- حد HTML المعاد من المكوّن44000 بايت لإبقاء السجل المشفر وإطار الاختبار ضمن حد stdout البالغ65536 بايت. CSS منفصل حتى64000 بايت، ووثيقة المعاينة الآمنة تخضع لحد الاستوديو العام.
- مهلة المكوّن10000ms داخل العزل، مع حدود الذاكرة وCPU والعملية القائمة. تجاوزها أو فشل المكوّن لا ينتج معاينة ناجحة كاذبة ولا يزيل آخر أثر محفوظ.
- المعاينة ناتج أولي غير تفاعلي. event handlers وuseEffect وhydration ليست جزءًا من العرض؛ صفحات Next التي تحتاج routing أو server actions أو API خاصة بالإطار تحتاج التوسعة اللاحقة.

## التحقق

تغطي `packages/studio-react/src/renderer.test.ts` التجميع دون تنفيذ المصدر على المضيف، وحصر الاستيرادات، ورفض غياب العزل أو إيصال غير مطابق أو فشل التنفيذ، وحد المخرجات وحجب HTML التنفيذي. تشمل تجربة Windows فعلية تشغّل React مع `useState` وصفحة ذات layout داخل AppContainer وتثبت وجود الناتج وربطه بملف المكوّن.

دليل العزل يثبت حد العملية التي شغلت المصدر وبصمة مدخلاتها. ناتج المشروع يُعامل كبيانات غير موثوقة ولا يعتبر بذاته اختبارًا لوظائف التطبيق أو مقارنة بصرية آلية. يسجل `IMPLEMENTATION-STATUS.md` نتيجة الرحلة النهائية وفحص الواجهة والتخزين.
