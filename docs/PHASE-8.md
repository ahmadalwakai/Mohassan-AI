# المرحلة الثامنة — مرافق Windows والتحكم المصرح

الحالة: ربط جهاز فعلي، وصور JPEG دورية من نطاق يختاره المستخدم محليًا، وعناصر UI Automation مقروءة، وإدخال فأرة ولوحة مفاتيح بإذن مؤقت. يعمل المرافق في جلسة Windows التفاعلية المفتوحة، مع نافذة موافقة مرئية وزر STOP محلي. لا يفعّل تثبيت هذه الشريحة ربط جهاز أو مشاهدة أو إدخال تلقائيًا.

## بدء الربط

1. شغّل التطبيق المعتاد، وافتح «التحكم في Windows» وأنشئ رمز ربط. الرمز عشوائي96bit، صالح لدقيقتين ويستخدم مرة واحدة، ولا توجد بيانات اعتماد افتراضية.
2. على جهاز Windows، شغّل المرافق من مجلد المشروع:

```powershell
pwsh -NoProfile -File scripts/windows-companion.ps1
```

عند وجود بوابة HTTPS معدة ومصرح بها، يمكن تحديد `-ServerUrl https://your-gateway.example`؛ العنوان الافتراضي محلي `http://127.0.0.1:4000`. يحتاج التشغيل Windows x64 و.NET Framework المثبت ومجلد المشروع الموثوق. يجمع المشغّل مصدر C# الموثوق إلى نسخة مرتبطة ببصمة المصدر داخل `.data/windows-native`، ثم يفتح نافذة تفاعلية مرئية.

3. ألصق الرمز في نافذة المرافق واضغط الربط محليًا. يظل المرافق دون صلاحيات مشاهدة أو إدخال بعد الربط وإعادة التشغيل.
4. اختر نافذة محددة أو سطح المكتب الأساسي. خيار سطح المكتب الكامل يعرض موافقة محلية صريحة. فعّل المشاهدة، والإدخال إن أردته، من الجهاز نفسه.
5. من مساحة العمل امنح «مشاهدة» أو «إدخالًا» لمدة30 أو60 أو120 ثانية. إذن المشاهدة لا يقبل أوامر إدخال. عند توفر صورة حديثة يمكنك النقر على الصورة، أو إرسال نص قصير أو مفاتيح محدودة.
6. زر STOP المحلي يلغي الموافقة فورًا دون انتظار الشبكة. إيقاف الجلسة من الويب يلغي الأذونات والأوامر المعلقة، ويحتاج موافقة محلية جديدة لاستئنافها. يمكن إلغاء ربط الجهاز لإبطال مفتاحه.

## حدود الثقة

- يحتفظ الخادم ببصمة مفتاح جهاز عشوائي256bit. المفتاح الخام يصل مرة واحدة إلى المرافق عبر الربط، ويحفظ هناك مشفرًا بـDPAPI للمستخدم الحالي؛ لا يرجع إلى واجهة الويب أو localStorage أو سجل التدقيق.
- رمز الربط دليل تفويض قصير خارج قناة الجهاز. نافذة المرافق تطلب إجراء المستخدم المحلي؛ البروتوكول لا يدعي تصديقًا عتاديًا أو attestation للبرنامج أو جهازًا خاليًا من الاختراق.
- مسارا POST المخصصان `/api/windows/companion/pair` و`/api/windows/companion/poll` مستثنيان فقط من سر وكيل Next، ويطبقان تحققهما المستقل. يرفضان Origin وFetch Metadata القادمة من متصفح، وحدود الطلبات والحجوم قائمة. بقية المسارات تحتاج جلسة المالك وسر الخدمة، وتحتاج الكتابة Origin الموثوق.
- HTTP متاح للمرافق المحلي loopback فقط؛ النقل الخارجي يحتاج HTTPS. المرافق يتحقق من شهادات TLS، ولا يتبع redirects أو يرسل cookies. البوابة العامة وتركيب TLS والتوزيع خارج الجهاز تحتاج إعداد نشر فعلي؛ لم يُنشأ tunnel أو منفذ عام تلقائيًا.
- الإذن مربوط بالمالك والجهاز وبصمة جلسة المتصفح والنطاق ونسخة الموافقة المحلية وتاريخ انتهاء. تغيير النطاق أو الموافقة المحلية يبطل توافق الإذن القديم. تسجيل الخروج يستدعي إلغاء أذونات Windows ورموز الربط غير المستهلكة المرتبطة بالجلسة.
- كل poll يحمل nonce ووقت إرسال حديثًا. أوامر الإدخال تحمل nonce منفصلًا وبصمة مدخلات وتسلسلًا متزايدًا ومعرف الإذن والصورة. تكرار الطلب نفسه يعيد الإيصال، وإعادة استعمال معرفه لمدخلات مختلفة تُرفض.

## الالتقاط والإدخال

المرافق يلتقط النافذة المحددة عبر `PrintWindow` لمنطقة العميل، أو الشاشة الأساسية عند الموافقة على سطح المكتب كاملًا. لا تُلتقط صور إلى الخادم قبل وجود إذن مشاهدة صالح. تُصغر الصورة إلى حد1024 بكسل لكل بُعد وتُضغط JPEG بحد200000 بايت. الإرسال دوري بمعدل يقارب صورة واحدة في الثانية، وليس بث فيديو WebRTC.

تقرأ UI Automation أسماء وأنواع وحدود ما يصل إلى100 عنصر في النطاق. لا تقرأ ValuePattern أو محتويات clipboard؛ أسماء الحقول المحمية تحجب أيضًا. العناصر المعروضة للقراءة، وليست مسارات حرة لاستدعاء UIA أو تشغيل أوامر.

قبل كل إدخال يتحقق المرافق من الجلسة التفاعلية واسم input desktop وصلاحية النطاق ومعرف الإذن والموافقة المحلية وتسلسل الأمر وانتهائه. يحتاج الأمر صورة معروفة لا يتجاوز عمرها3 ثوان، ويعيد المرافق التقاط النطاق ومقارنة بصمة البكسلات قبل الإدخال. اختلاف الشاشة يرفض الإجراء ويطلب صورة جديدة.

النطاق المقيد لنافذة لا يرسل الإدخال حتى تصبح تلك النافذة نفسها في المقدمة، مع تطابق HWND وهوية العملية ووقت بدئها. يمنع اختبار المفاتيح المضغوطة محليًا دمج الإدخال مع Ctrl أوAlt أوWin أوShift موجودة. تسمح القائمة بنقرات وأحرف Unicode حتى120 حرفًا ومفاتيح تنقل محددة وتمرير محدود؛ لا توجد API لتشغيل shell أو ملفات أو أوامر نظام.

تُرسل الأحداث عبر `SendInput` ويُتحقق من العدد المقبول. هذا يؤكد إرسال الإدخال إلى Windows؛ ليس دليلًا على نجاح عملية أعمال داخل التطبيق. الإدخال الجزئي أو النتيجة المفقودة يبقيان حالة غير محسومة ولا يعادان تلقائيًا. لا يمكن سحب حدث سبق أن قبله نظام التشغيل؛ زر STOP يمنع الإدخال اللاحق ويعاد فحصه بعد أي التقاط حاجب وقبل إرسال الأحداث.

## التوقف والتعافي

- قفل الجلسة أو logoff أو input desktop آمن أو فشل الالتقاط يمنع الإدخال. لا يعمل المرافق كخدمة Session0، ولا يتجاوز شاشة UAC أو القفل أو حدود UIPI.
- STOP المحلي يغير نسخة الموافقة ويمسح الأذونات والإطارات المعروفة. لا يحتجز الإدخال قفل حالة المرافق أثناء استدعاء التقاط قد يتعثر، لذلك يبقى زر الإيقاف المحلي مستجيبًا. watchdog يوقف الموافقات إذا تعثر عمل المرافق أكثر من4 ثوان.
- عند انقطاع الاتصال يوقف المرافق الموافقات. يرفض الخادم الإدخال دون heartbeat حديث وصورة جديدة. ينتهي أمر غير منفذ بعد ثانيتين؛ لا يعاد تسليم أمر سبق dispatch له بعد فقد الرد.
- إلغاء إذن لأمر queued يرفضه؛ أمر dispatched بلا تأكيد يبقى unknown. محتوى النص في الأمر المؤقت يفرغ بعد الإقرار أو الإلغاء أو انتهاء المهلة؛ سجل التدقيق يحفظ نوع الإجراء وعدد الأحرف والإيصال فقط.
- يحتفظ SQL بآخر صورة فقط، وتحجب القراءة بعد انتهاء الإذن أو انقطاع الجهاز؛ تنظيف دوري يمسح الصورة القديمة ورموز polling المنتهية. سياسات الاحتفاظ الشاملة والنسخ الاحتياطي تخص مرحلة الموثوقية.

## ما تحقق فعليًا

`packages/windows/src/windows.test.ts` يغطي الهوية والملكية، والرمز القصير أحادي الاستخدام، ورفض المتصفح، ورفض poll قديم أو مكرر، وفصل view/control، وربط جلسة المتصفح، وإلغاء الأذونات، ومنع تعارض nonce، والتسليم مرة واحدة، وتنقيح النص من التدقيق، وحفظ نتيجة غير محسومة عند الإيقاف بعد dispatch.

اختبار Windows الأصلي يجمع C# ويفتح نافذة WinForms اختبارية مملوكة لعملية الاختبار فقط. يثبت JPEG حقيقيًا وعناصر UIA، ونقرة فأرة حقيقية واحدة وكتابة Unicode عبر SendInput إلى هذه النافذة. ويثبت رفض إذن المشاهدة والإعادة والانتهاء والصورة القديمة وتغير بكسلات الشاشة والإذن الخطأ وSTOP. وضع الاختبار يرفض صراحةً أي هدف خارج عملية نافذته، بما فيه سطح المكتب؛ لا يلتقط تطبيقات المستخدم أو يدخل إليها، ولا يربط جهاز المالك.

هذه الأدلة محلية على Windows الحالي. التوزيع الموقّع وتثبيت موثوق على أجهزة أخرى والبوابة العامة والمراقبة التشغيلية والاختبارات عبر شبكة خارجية تحتاج تجهيز بيئة النشر والاعتمادات المناسبة. لا يدعي نجاح نافذة الاختبار تشغيل تحكم إنتاجي على جهاز بعيد لم يُربط بعد.
