# Capability benchmark v2 data cards and mapping

Mapping version `1` admits human-written material from the releases below. The corpus code contains upstream links, filtering rules, quotas, and a SHA-256 manifest for the committed sealed release. The release includes the selected rows, original binary seed, and attribution bundle. The import commands only fetch data and operate on it locally. The benchmark evaluates the product offline.

## Data cards

The fingerprints are SHA-256 of the original downloaded bytes. The importer verifies the hash on both cache hits and downloads. All source credits remain with the release. The adapters select, reformat, and annotate the original items as described below.

## Candidate decisions

- **QReCC** licenses its data under CC BY-SA 3.0 and includes human rewrites, with some of the same QuAC material. CANARD provides one source for the supplied-history rewrite stratum. [QReCC license](https://github.com/apple-aiml-research/ml-qrecc/blob/1d174464290790c0198b474ad022952ecd83b76b/README.md#license)
- **CoNaLa** has a human-curated set and automatically mined data. The underlying Stack Overflow snippets require per-source attribution and review of the applicable CC BY-SA versions. The sanitized MBPP subset provides an eligible original test split with a published protocol for the coding measure. [CoNaLa release](https://conala-corpus.github.io/) · [Stack Overflow licenses](https://stackoverflow.com/help/licensing)
- **Arabic arithmetic and dialect**. The authors of TyDi QA-WANA document native human contributions, but the publisher download returned `AccessDenied` and an eligible pinned copy could not be verified. MADAR terms disallow modification, WASIL is CC BY-NC-SA, and ArabCulture-Dialogue describes GPT-5 drafting before human edits. Human-translated MGSM lacks Arabic. Public Arabic GSM8K adaptations examined were model-translated or lacked verified data licensing and authorship, and the ArMATH source has no dataset license. Arabic in MASSIVE, Mintaka and TyDi is reported as `unspecified` for variety using the release’s locale or language metadata. [TyDi QA-WANA](https://arxiv.org/abs/2507.17709) · [MADAR](https://camel.abudhabi.nyu.edu/madar-parallel-corpus/) · [WASIL](https://huggingface.co/datasets/QCRI/WASIL) · [ArabCulture-Dialogue process](https://huggingface.co/datasets/Almheiri/ArabCulture-Dialogue#dataset-creation) · [MGSM](https://github.com/google-research/url-nlp/tree/main/mgsm) · [ArMATH](https://github.com/reem-codes/ArMATH)

## Reviewed mapping, version 1

The adaptations were checked against the source labels, release structure, and Mohassan's route, tool, status and answer contracts. The source-specific tests exercise positive and dropped cases. Mapping is independent of the product's measured outcomes. A change to the task or scoring contract requires a new reviewed mapping version and a new seal before making performance comparisons.

| Source | Admission and expectations | Measured scope |
| --- | --- | --- |
| CLINC150 | `thank_you`, `goodbye`, `what_is_your_name` and `are_you_a_bot` map to a local `chat` completion with label-appropriate response phrases. Direct `repeat` with no previous turn asks which item to repeat. Selected action labels such as `book_flight`, `make_call` and `play_music` require explicit intent to act. The `oos_test` branch admits only narrowly matched unsupported third-party actions. Explicit integer binary `calculator` utterances can map to `compute` and `calculate`. | The dataset's out-of-scope label is relative to CLINC150. The sealed set reserves six CLINC150 out-of-scope cases and uses GSM8K for arithmetic. |
| MASSIVE | Explicit media playback, connected-device control, and third-party send, order or publish actions map to unsupported capability. `datetime_convert` with an unresolved location or time zone maps to one relevant clarification and `waiting_user`. The Arabic import additionally requires Arabic script and a majority of human intent judgments with score `1`. Exact name questions can map to `chat`. | Media may use its dedicated route if it explicitly declines the immediate playback action. Selectors reject some ambiguous commands or requests to open apps or find information. Singleton name strata are left out of the sealed sample. |

## Reproducing and running the seal

The committed seal follows the honor rule beside the payload. Keep v2 closed during development. Freeze the candidate commit and settings, run v2 once, and keep the aggregate receipt. The v1 development runner rejects paths into the v2 seal directory. The v2 runner requires the complete release and verifies every pinned file before evaluation. [Honor rule and run command](../tests/fixtures/agent-capability-bench/v2/sealed/README.md) · [Manifest](../scripts/agent-capability-bench/v2/manifest.json)

All seven sources in the original 1,200-case release permit redistribution with the included credits and license terms. Zero sources and zero cases were excluded for redistribution. The collection retains the source-specific licenses, the applicable ShareAlike terms for CANARD and QuAC adaptations and Wikipedia excerpts, and article-level contributor attribution. The upstream data files are retrieved on demand. [Release attribution](../tests/fixtures/agent-capability-bench/v2/sealed/attribution/ATTRIBUTION.md)

Use the original seed when verifying this release. The sampler ranks rows with keyed SHA-256 and fixed quotas. It samples one row per source family across parallel translations, conversation IDs or TyDi articles, and excludes normalized input sequences already present in either v1 partition. Each sampled stratum retains at least one alternative after exclusions. The public seed makes exact membership reproducible. SHA-256 pins the bytes, and the honor rule protects the holdout during iteration.

A custodian can rebuild the release from a fresh checkout with Node 24, the lockfile dependencies, `curl` and `tar`. The output parent must exist outside the checkout. The builder independently retrieves and verifies the upstream data and notices, regenerates the cases, accounting and article-attribution index, and takes the authored release README and attribution summary from the frozen checkout.

```bash
set -euo pipefail
seal=tests/fixtures/agent-capability-bench/v2/sealed
scratch=$(mktemp -d)
node --import tsx scripts/agent-capability-bench/v2/import.ts \
  --cache "$scratch/source-cache" --seed "$seal/sampling-v2.seed" --out "$scratch/rebuilt"
cmp "$scratch/rebuilt/manifest.json" scripts/agent-capability-bench/v2/manifest.json
while IFS= read -r -d '' file; do
  cmp "$file" "$scratch/rebuilt/release/${file#"$seal"/}"
done < <(git ls-files -z -- "$seal")
```

`--inventory true` reports source counts without rebuilding a seal. The audit records the two verified rebuilds and the baseline rerun from the committed bundle. [Baseline audit](CAPABILITY-BENCH-V2-2026-11-25.md)
