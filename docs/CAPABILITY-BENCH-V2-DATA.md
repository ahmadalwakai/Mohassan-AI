# Capability benchmark v2 data cards and mapping

Mapping version `1` admits human-written material from the releases below. The public corpus code contains upstream links, filtering rules, quotas, and the sealed payload's SHA-256. The selected rows, their source identifiers, and the custodian seed stay in private storage. The import commands only fetch data and operate on it locally. The benchmark evaluates the product offline.

## Data cards

The fingerprints are SHA-256 of the original downloaded bytes. The importer verifies the hash on both cache hits and downloads. All source credits remain with the release. The adapters select, reformat, and annotate the original items as described below.

## Candidate decisions

- **QReCC** licenses its data under CC BY-SA 3.0 and includes human rewrites, with some of the same QuAC material. CANARD provides one source for the supplied-history rewrite stratum. [QReCC license](https://github.com/apple-aiml-research/ml-qrecc/blob/1d174464290790c0198b474ad022952ecd83b76b/README.md#license)
- **CoNaLa** has a human-curated set and automatically mined data. The underlying Stack Overflow snippets require per-source attribution and review of the applicable CC BY-SA versions. The sanitized MBPP subset provides an eligible original test split with a published protocol for the coding measure. [CoNaLa release](https://conala-corpus.github.io/) · [Stack Overflow licenses](https://stackoverflow.com/help/licensing)
- **Arabic arithmetic and dialect**. The authors of TyDi QA-WANA document native human contributions, but the publisher download returned `AccessDenied` and an eligible pinned copy could not be verified. MADAR terms disallow modification, WASIL is CC BY-NC-SA, and ArabCulture-Dialogue describes GPT-5 drafting before human edits. Human-translated MGSM lacks Arabic. Public Arabic GSM8K adaptations examined were model-translated or lacked verified data licensing and authorship, and the ArMATH source has no dataset license. Arabic in MASSIVE, Mintaka and TyDi is reported as `unspecified` for variety using the release’s locale or language metadata. [TyDi QA-WANA](https://arxiv.org/abs/2507.17709) · [MADAR](https://camel.abudhabi.nyu.edu/madar-parallel-corpus/) · [WASIL](https://huggingface.co/datasets/QCRI/WASIL) · [ArabCulture-Dialogue process](https://huggingface.co/datasets/Almheiri/ArabCulture-Dialogue#dataset-creation) · [MGSM](https://github.com/google-research/url-nlp/tree/main/mgsm) · [ArMATH](https://github.com/reem-codes/ArMATH)

## Reviewed mapping, version 1

The adaptations were checked against the source labels, release structure, and Mohassan's route, tool, status and answer contracts. The source-specific tests exercise positive and dropped cases. Mapping is independent of the product's measured outcomes. A change to the task or scoring contract requires a new reviewed mapping version and a new seal before making performance comparisons.

| Source | Admission and expectations | Measured scope |
| --- | --- | --- |
| CLINC150 | `thank_you`, `goodbye`, `what_is_your_name` and `are_you_a_bot` map to a local `chat` completion with label-appropriate response phrases. Direct `repeat` with no previous turn asks which item to repeat. Selected action labels such as `book_flight`, `make_call` and `play_music` require explicit intent to act. The `oos_test` branch admits only narrowly matched unsupported third-party actions. Explicit integer binary `calculator` utterances can map to `compute` and `calculate`. | The dataset's out-of-scope label is relative to CLINC150. Mohassan refusals require its own route, no clarification or external effect, and an explicit inability statement. The sealed set reserves six CLINC150 out-of-scope cases and uses GSM8K for arithmetic. |
| MASSIVE | Explicit media playback, connected-device control, and third-party send, order or publish actions map to unsupported capability. `datetime_convert` with an unresolved location or time zone maps to one relevant clarification and `waiting_user`. The Arabic import additionally requires Arabic script and a majority of human intent judgments with score `1`. Exact name questions can map to `chat`. | Media may use its dedicated route if it explicitly declines the immediate playback action. Selectors reject some ambiguous commands or requests to open apps or find information. Singleton name strata are left out of the sealed sample. |
| Mintaka | `comparative` maps to `comparison`. Other supported labels map to `factual`. Public lookup must read evidence and complete with each required entity label, literal or numeric answer. Boolean, unlinked, missing localized entity labels, unsupported formats, and answers already present in the question are dropped. | Replay serves the original annotated question and answer as evidence, with a short heading. This measures routing and answer use when the gold annotation is available. Live retrieval, independent corroboration, and comparative reasoning without supplied evidence fall outside this measure. |
| TyDi QA GoldP | Verify original answer byte offsets against the passage. Keep independently matchable literals or numbers; drop answer sets with no scoreable value. Require public lookup, a successful read, completion and a gold span or its numeric value. | Replay serves the archived passage on a recorded full-question, normalized-question or article-title search. The reader treats a permitted unrecorded Arabic/English Wikipedia article probe as unavailable. Unknown search queries and other unrecorded tools remain fixture misses. This is controlled evidence retrieval, with lexical answer matching. |
| CANARD | Supply original article and section titles and prior human questions and answers as labeled history. Require a `writing` transform and the human standalone rewrite as a normalized literal substring, with a uniform instruction to omit ending punctuation. Drop first turns and unchanged or unscoreable rewrites. | Covers reference restoration with supplied context. Valid paraphrases can fail the single-reference check. Extra non-question prose surrounding the reference can pass. The supplied history is part of one product request. |
| GSM8K | Map the human problem to `compute` plus `calculate`, completion and the numeric `####` answer. The product sees the problem only. No web tools are allowed. | Numeric token matching can pass when the right number appears alongside other numbers. This measures numeric token presence only. |
| MBPP | Apply the published test-inclusive prompt format using the original problem text and assertions. Keep consistent direct calls to a declared entry point where no test imports are required. Require the `coding` route and a matching Python declaration in the answer. | Tests and reference code are inspected as text. Execution and functional correctness fall outside the route and interface check. |

The source accounting includes each test row or language variant examined in the release-specific split. `admitted` is the count before the sampling filter and deduplication. `dropped` reports why candidates could not be scored faithfully. Fixed quotas by source, area and language are in the versioned sampling policy. ## Custodian procedure

Use an access-controlled directory outside the checkout. Keep the 32-byte release seed separate from the payload, with both limited to the benchmark custodian. Once mapping and quotas are frozen, run the importer with the same source revisions, mapping tree, and seed to reproduce the exact release. `--inventory true` can inspect counts before a new seal without a seed. Run the development benchmark directly from the public checkout with its ordinary v1 command. A release evaluation uses only the v2 runner and the external payload. Keep raw logs alongside the private audit receipt and publish aggregate results.

```bash
# Run the first three commands only when creating a new seal.
umask 077
install -d -m 700 "$CUSTODY"
openssl rand -out "$CUSTODY/sampling-v2.seed" 32
node --import tsx scripts/agent-capability-bench/v2/import.ts \
  --cache "$CUSTODY/source-cache" --seed "$CUSTODY/sampling-v2.seed" \
  --out "$CUSTODY/release"
sha256sum "$CUSTODY/release/payload.json"
cmp "$CUSTODY/release/manifest.json" scripts/agent-capability-bench/v2/manifest.json
npm run assistant:capability-bench -- --version 2 \
  --sealed "$CUSTODY/release/payload.json" --output "$CUSTODY/new-receipt.json"
```

Keep a copy of these data cards with the private release. Preserve MASSIVE's `1.1/LICENSE` and `1.1/NOTICE.md`, the CLINC150 and GSM8K license files, the MBPP and TyDi upstream Apache notices, and the Mintaka and CANARD release notices linked above. Any transfer of the private adapted payload retains attribution, applicable license terms, and share-alike obligations. Keep the source archive and the holdout out of training and tuning inputs.

The sampler ranks each row with a private keyed SHA-256 and fills fixed quotas in rounds. It samples one row per source family across parallel translations, conversation IDs or TyDi articles, and excludes normalized input sequences already present in either v1 partition. Every sampled stratum must have an independent alternative left after exclusions. Public source material and mapping are discoverable. The seal controls exact membership and prevents fixture or expectation changes under a pinned receipt. Rebuilds and receipt completion can be tracked by SHA-256 without exposing case identifiers.
