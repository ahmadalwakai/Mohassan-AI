# التكامل المستمر عبر GitHub Actions

يعمل سير العمل عند فتح طلب سحب أو تحديثه باتجاه `feat/skill-engine` أو `main`، وعند الدفع إلى `feat/skill-engine`. تُلغى التشغيلات السابقة لنفس المرجع عند بدء تشغيل أحدث، ولكل مهمة حد زمني.

- **Node** يثبّت الاعتماديات عبر `npm ci` باستخدام Node.js 24، ويفحص أنواع TypeScript في جذر المستودع وتطبيق الويب، ثم يشغّل مجموعة اختبارات Vitest كاملة. يستخدم Playwright متصفح Chromium، وتستخدم اختبارات قاعدة البيانات PGlite من دون خدمة PostgreSQL منفصلة. عند فشل الاختبارات يظهر تقرير JUnit ضمن مرفقات التشغيل باسم `vitest-report`.
- **بناء الويب** يشغّل `npm ci` ثم `npm run build` لبناء تطبيق Next.js 16 عبر Webpack. لا يحتاج البناء إلى متغيرات بيئة أو قيم بديلة.
- **Android** يشغّل اختبارات الوحدة لإصدار التصحيح عبر `./gradlew testDebugUnitTest` داخل `apps/android` باستخدام JDK 17.

هذه المهام للفحص والبناء فقط، ولا تتضمن نشرًا أو أسرارًا أو طلبات إلى موقع الإنتاج أو واجهات ذكاء اصطناعي خارجية.
