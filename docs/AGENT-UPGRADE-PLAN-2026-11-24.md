# خطة تطوير قدرات وكيل موحسن

تاريخ البدء: 24 نوفمبر 2026. طلب المالك وضع خطة والبدء بتنفيذها مع استمرار التدريب. الهدف الأول رفع نجاح المهام العربية والإنجليزية المحددة: فهم المتابعات، واختيار المهارة، وتنفيذ أجزاء الطلب والتحقق من النتيجة. المنافسة العامة مع Claude تحتاج تقييمًا لاحقًا وقدرات نموذج تتجاوز نطاق تدريب المحادثة الحالي.

تحديث الدفعة الثانية: أذن المالك صراحة بتثبيت ودفع جميع التغييرات المحلية القديمة والجديدة مع استمرار التدريب. يتقدم هذا الإذن على المنع السابق لـcommit وpush في هذه الدفعة. المعايير المثبتة والحدود في [خطة الدفعة الثانية](AGENT-UPGRADE-BATCH2-2026-11-24.md)، والنتائج الفعلية في [تقريرها](AGENT-UPGRADE-BATCH2-RESULTS-2026-11-24.md).

## حدود التنفيذ أثناء التدريب

- يبقى تدريب v5 وعمليته وإعداداته وبياناته ومُرمّزه وأوزانه وأقفاله كما هي. تشمل الحماية ملفات Python المثبتة في `artifacts/chat-training/v5/foundation-20261123/config.json` ولو كانت خارج `artifacts`.
- لا استدلال على CPU أو GPU، ولا تجهيز بيانات كثيف، ولا اختبارات شاملة أو Playwright أو تشغيل خدمات أو إعادة تشغيلها أثناء هذه الدفعة. يسمح بفحوص الوحدات المتأثرة فقط، بالتتابع وعامل واحد وأولوية منخفضة، مع قراءة سجل سرعة التدريب قبلها وبعدها. إذا ظهر هبوط مستمر مرتبط بالفحص ينتهي الفاحص وحده.
- لا خدمات ذكاء خارجية أو أوزان أو مُرمّزات أو تضمينات جاهزة. لا وصول إلى قاعدة الإنتاج، ولا قراءة للاختبارات المختومة، ولا تغيير بوابات التدريب أو إعادة محاولة بوابة العقل المستقلة السابقة.
- لا نشر ولا تفعيل لنموذج المحادثة أو الهاتف ضمن هذه الدفعة. التغييرات في المصدر المحلي؛ الفحص الشامل لتدفق المستخدم يأتي بعد التدريب أو على جهاز منفصل.
- تحفظ أعمال الوكلاء السابقة. لا commit أو push أو stash أو reset أو إعادة تنسيق عامة.

## التقييم الاستراتيجي

- **القوة:** توجد بالفعل أدوات وعزل للعمل البرمجي وذاكرة وسجل تنفيذ وحواجز للتحقق والخصوصية.
- **الضعف:** فهم المحادثة v2 مراقبة فقط؛ مطابقة المهارات تفوّت طلبات صحيحة؛ البرمجة محدودة ومرتبطة بمزوّد خارجي في مسارها الحالي.
- **الفرصة:** تحسين نجاح مهام واضحة بالعربية والإنجليزية باستخدام البنية الموجودة، مع فصل تطوير الوكيل عن تدريب نموذجه.
- **الخطر:** نجاح اختبار نصي قد يخفي جوابًا غير صحيح، وتوسيع التوجيه قد يخلط طلبًا شخصيًا ببحث عام، والفحص الثقيل قد يزاحم التدريب.

التوصية: البدء بإصلاحين صغيرين في المسارات الحالية، ثم توسيع التخطيط والبرمجة على أساس معايير نتيجة نهائية قابلة للفحص. لا ترقية شاملة لوضع المراقبة ولا تغيير للمعمارية اللغوية الجارية.
