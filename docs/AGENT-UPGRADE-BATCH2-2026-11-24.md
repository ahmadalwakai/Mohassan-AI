# تطوير الوكيل — الدفعة الثانية، 24 نوفمبر 2026

طلب المالك البدء بالتطوير مع استمرار التدريب، ثم تثبيت ودفع التغييرات المحلية القديمة والجديدة. هذا إذن صريح بـcommit وpush لهذه الدفعة، ويتقدم على المنع السابق لهما؛ لا يشمل تغيير التدريب أو تشغيل نموذج أو نشر يدوي أو تفعيل الهاتف.

## القرار وحدود التنفيذ

- القوة: توجد عقود خطوات وتحقق وصلاحيات وذاكرة بعزل المالك؛ نكملها في مساراتها الحالية.
- الضعف: سجل الخطوات يقطع الخطة عند سقفها، وملصقات التقدم ليست إثبات تنفيذ؛ البحث في الذاكرة يستبعد القديم قبل حساب الصلة.
- الفرصة: تحسين إكمال المهام واسترجاع الحقائق دون نموذج إضافي أو تغيير التدريب.
- الخطر: نجاح كاذب، تكرار أثر مجهول عند الاستئناف، أو تزاحم الفحص مع التدريب.

التوصية: تثبيت شروط الإكمال وتسجيل التنفيذ أولًا، ونقل ترتيب صلة الذاكرة إلى الاستعلام المحدود. لا نوسع المخطط العام أو نعيد فتح بوابة العقل المتوقفة.

عملية التدريب وإعداداتها وبياناتها ومُرمّزها وأوزانها وأقفالها وملفات Python المثبتة تبقى كما هي. لا استدلال CPU/GPU، ولا اختبارات شاملة أو متصفح أو بناء أو إعادة تشغيل خدمة. الاختبارات المحددة وحدها بالتتابع، بعامل واحد وأولوية منخفضة وعلى معالج منطقي واحد؛ تراقب سرعة التدريب، وينتهي الفاحص وحده عند هبوط مستمر مرتبط به. لا وصول إلى قاعدة الإنتاج أو الاختبارات المختومة.

## معايير القبول المثبتة قبل التعديل

### اكتمال الخطة

1. تقبل الخطة كاملة أو ترفض كاملة قبل أي أثر؛ لا قص أو تسجيل جزئي عند تجاوز سقف العقد الحالي.
2. تسجيل الخطة نفسها واستعادتها يحافظان على هوية خطواتها دون تكرار؛ اختلاف المحتوى لا يستعير إيصال خطة سابقة.
3. لبدء الخطوة وإتمامها إشعار مستقل عن نص التقدم؛ انتقال المؤشر أو تغير ملصق العرض لا يثبت النجاح.
4. لا تؤكد خطوة مطلوبة متروكة أو معلقة أو مجهولة الأثر إكمال المهمة، ولا تسمح بتجاوز تبعية مطلوبة غير متحققة.
5. يبقى الأثر المجهول مجهولًا ولا يُعاد تلقائيًا. الموافقات وحدود الصلاحية تبقى عند حدودها الحالية.
6. تطبيع أي توسعة حتمية للخطوات يحدث قبل التسجيل؛ رفض التسجيل أو بدء الخطوة يمنع الوصول إلى الأداة.
7. أحكام completed وpartial وblocked تعكس النتائج الفعلية؛ الأدلة الإرشادية لا تتحول إلى شروط إلزامية.

### استرجاع الذاكرة

1. يسترجع عنصرًا ذا صلة حتى إذا سبقته أكثر من 300 ذاكرة أحدث، ويرتب قوة الصلة قبل الحداثة.
2. يطبق ملكية المالك والمهمة والطبقة والانتهاء وصلاحية جميع الأسانيد قبل تحديد عدد المرشحين، ويستبعد السند الأجنبي أو الملغى أو المنتهي أو الغائب.
3. يحافظ على NFKC وحالة الأحرف وإزالة التشكيل، ويعامل رمزي % و_ كنص لا كحروف بحث شاملة.
4. البحث الفارغ يعيد أحدث العناصر الصالحة بالحد المعتمد؛ والطلب readOnly لا يكتب بيانات.
5. لا واجهة عامة أو اعتماد جديد أو ترحيل قاعدة بيانات. الفحص على قاعدة مؤقتة فقط.
