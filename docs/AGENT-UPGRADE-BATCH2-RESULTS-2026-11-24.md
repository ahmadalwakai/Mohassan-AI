# نتائج تطوير الوكيل — الدفعة الثانية، 24 نوفمبر 2026

طلب المالك البدء بالتطوير دون إيقاف التدريب، ثم تثبيت ودفع التغييرات المحلية القديمة والجديدة. نُفذت هذه الدفعة في مسارات الوكيل والذاكرة، دون تشغيل نموذج أو خدمة أو متصفح أو الوصول إلى قاعدة الإنتاج. لا تدعي هذه النتائج منافسة Claude أو إكمال المخطط العام.

## ما تغير ولماذا

- `assistant/run-plans.ts` و`assistant/hands.ts`: تقبل خطة المتصفح كاملة أو ترفضها قبل التنفيذ؛ لا تُقص عند سقف العقد. هوية الخطوات ثابتة ببصمة محتواها، ويُتحقق من تطابقها عند الاستعادة. توسعة البحث المقيد بالموقع تحدث قبل التسجيل مع حفظ طلب الجواب وصيغته. بدء الخطوة وإتمامها مستقلان عن ملصقات التقدم.
- `command-chat.ts`: قبول الخطة وبدء الخطوة إلزاميان؛ لا يبتلع مسار السجل أخطاءهما ثم ينفذ الأداة. تحفظ الحالة قبل الفعل وبعد إيصال النتيجة. نتيجة الفعل الموافق عليه تُسوّى بعد عودته فقط، بموافقته المحددة المستهلكة؛ إرسال نموذج بحث لا يثبت اكتمال قراءة نتائجه. الجواب الذي يرفضه الحَكَم يُسحب تحقق خطوته، سواء انتهت ميزانية التصحيح أم فشلت القراءة الثانية.
- `assistant/agent-run.ts`: الخطوة المطلوبة المتروكة لا تعني نجاحًا، ولا تسمح بتجاوز تبعيتها. الأثر المجهول لا يُعاد تلقائيًا. تُحسب جميع معايير التحقق قبل تحديد عدد المعايير المعروضة؛ تُقدّم المعايير المطلوبة غير المحققة عند امتلاء العرض.
- `packages/memory/src/index.ts`: صلة النص وملكية الذاكرة وصلاحية جميع أسانيدها تُفحص في SQL قبل حد النتائج. تعود المعلومة القديمة المناسبة حتى إذا سبقتها ذاكرات أحدث كثيرة. بقيت واجهة البحث وسياسة التطبيع و`lexical-v1` كما هي، بلا نموذج أو تضمينات أو ترحيل قاعدة بيانات.

المعايير الأساسية ثُبتت قبل التعديل في [خطة الدفعة الثانية](AGENT-UPGRADE-BATCH2-2026-11-24.md)، ببصمة `d5597cf6e319df10f42995c38e7e8696e216a826ab3d42a3a0944abb9f79b0a5`. أضيف أثناء المراجعة اختبار رفض الجوابين واختبار بقاء البحث المركب غير متحقق بعد إرسال نموذجه، لمنع نجاح كاذب كشفته مراجعة المصدر.

## استمرار التدريب

خلال فحوص الوحدات والأنواع، أُخذت 96 عينة: بقيت كلها `running`، وكانت قيمة `consecutive_slow_seconds` القصوى صفرًا. السرعات المرصودة بين 5021.006 و5943.601 موضعًا في الثانية. هذه ملاحظة استمرار التدريب وعدم بلوغ حارس الهبوط المستمر، وليست تجربة تثبت غياب كل أثر على الموارد. البيانات في `*-training-during.jsonl` و`training-verification-summary.json`.

قبل فحص الذاكرة سجل التدريب 188,817,664 موضعًا، وبعد فحص الأنواع سجل 191,480,064 موضعًا. المخرجات الخام `memory-focused-training-before.json` و`root-typecheck-training-after.json`. تحققت بصمات ملفات المصدر الصغيرة الـ25 المثبتة في إعداد التدريب، وجميعها مطابقة؛ `training-source-pins-before-commit.json`. لم تُحسب بصمات الأوزان أو البيانات الكبيرة، ولم تتغير عملية التدريب أو إعداداته أو أقفاله أو المُرمّز أو الأوزان أو بياناته.
