وصلة — النسخة الهجينة للمراجعة
٢ نوفمبر ٢٠٢٦

ما الذي تغيّر؟
أصبحت المحادثة تمر بمحرك وصلة قبل استدعاء النموذج. الحسابات وتحويل الوحدات تعمل دون نموذج؛ استرجاع الملاحظات العادي يعرض النص المحفوظ مباشرة؛ الكتابة والتحليل يستخدمان نموذج Qwen المثبّت الحالي. الأسئلة الحديثة تُوجّه إلى البحث، مع روابط حقيقية وحالة الأدلة. لا يوجد نموذج جديد أو تنزيل إضافي للنماذج.

تنفيذ الأوامر
يدعم الإصدار الحالي «افتح المتصفح»، «افتح المفكرة»، «افتح الآلة الحاسبة»، وفتح رابط HTTPS عام محدد. يتطلب الاقتران وخيار «السماح بفتح التطبيقات من المحادثة» على لوحة Windows. الخيار مغلق افتراضيًا، ومستقل عن التحكم بالفأرة ولوحة المفاتيح.
لا ينفذ نصًا برمجيًا أو أوامر طرفية حرة. لا تصل نصوص المصادر أو إجابات النموذج إلى منفذ الأوامر. يحتفظ بمعرّف لكل طلب فتح لمنع تكراره بعد انقطاع الاتصال أو إعادة التشغيل. عبارة «أُرسل طلب الفتح» تعني أن Windows استلم الطلب؛ لا تعني أن ظهور النافذة تحقق بصريًا. اختبارات الفتح استخدمت منفذًا بديلًا وهميًا، ولم يُجر اختبار الإدخال الفعلي المؤجل بطلب المستخدم.
نسخة TestFlight 1.0(4) لا ترسل معرّف أوامر المحادثة الجديد؛ يلزم إصدار محدث قبل استخدام هذه الميزة من الهاتف.

الواجهة
web/ تطبيق Next.js App Router وTypeScript وChakra UI، بالعربية والإنجليزية. يتضمن المحادثة واختيار المسار والمعرفة والمحادثات المحفوظة وحالة المساعد. رمز الربط من ٨ أرقام، وبيانات الجلسة في ملف تعريف ارتباط HttpOnly مشفّر، وليس التخزين المحلي للمتصفح.
تطبيق iOS الأصلي يحتفظ بأقسام سطح المكتب والصور والبحث، وأضيفت إلى محادثته خيارات المسار والذاكرة والمصادر. واجهة الويب الجديدة مخصصة للمساعد والمعرفة وأوامر فتح التطبيقات؛ عرض سطح المكتب وإنشاء الصور يظلان في تطبيق iOS الحالي.

الذاكرة والخصوصية
«احفظ هذه المحادثة» و«استخدم معرفتي» خياران منفصلان ومغلقان افتراضيًا. لا يُحفظ نص المحادثة عند غياب الموافقة الصريحة في الطلب. إضافة مستند إلى المعرفة عملية منفصلة؛ يمكن حذف المستند أو المحادثة من الواجهة.
تشارك الأجهزة المقترنة بهذه النسخة الشخصية معرفة تركيب Windows نفسه. ليست منصة متعددة العملاء. حذف المحادثة يحذف رسائلها ومصادرها وعمليات البحث المرتبطة بها. إحصاءات الاستخدام لا تحتوي السؤال أو الإجابة. إعداد الذاكرة المحفوظ لا يلغي شرط الاختيار الصريح لكل إرسال.
SQLite هو التخزين المحلي الافتراضي. قاعدة Neon الخاصة «Wasla Hybrid AI» مهيأة، واختُبر فيها الحفظ الاختياري والحذف وترتيب الرسائل عبر TLS مع التحقق الكامل من الشهادة. الجداول: conversations، messages، knowledge_documents، web_sources، research_runs، usage_metrics، وإعدادات المحرك. لا تحتوي قاعدة الاختبار نصوص محادثات المستخدم السابقة.

الدقة وحدودها
المراجع تأتي من نتائج البحث الفعلية، وتُفحص صلتها بالكلمات الأساسية للسؤال. تُستبعد النتائج المكررة أو المتشابهة والتعليمات المشبوهة. الملخصات تُرفض إذا تضمنت مراجع أو روابط غير واردة أو اقتباسات لا تطابق المقتطفات.
النسخة المحلية تقرأ مقتطفات البحث، ولا تزعم أنها فتحت كل صفحة أو أثبتت صحة كل ادعاء. مقارنة الأرقام المتعارضة فحص تقريبي للسياق المتشابه؛ ليست إثباتًا للتعارض الدلالي. تعدد النطاقات لا يثبت استقلال المصادر. يُعرض وقت الاسترجاع، ويظل تاريخ النشر فارغًا عند غيابه. لا يوجد ضمان رياضي بأن النموذج لن يخطئ.
البحث المجاني يستخدم DuckDuckGo HTML ثم Bing RSS؛ قد يُحجب أو يعيد نتائج غير مفيدة. عند نقص الأدلة يعرض المحرك ذلك صراحة، ولا يعوّضها بروابط مخترعة. الاسترجاع اللغوي للمعرفة يعتمد كلمات النص، وليس بحثًا دلاليًا بالمتجهات.

تشغيل المعاينة محليًا
1. شغّل خدمة Windows باختيار عنوان خاص وشهادة موثوقة، أو بيئة الاختبار المعزولة على 127.0.0.1:47622.
2. من مجلد web نفذ npm ci. انسخ .env.example إلى .env.local واملأ مفتاح جلسة عشوائيًا من ٣٢ بايت، وعنوان الخدمة وبصمتها ومسار شهادتها العامة. لا تضع مفتاح الشهادة الخاص في الويب.
3. نفذ npm run dev -- --hostname 127.0.0.1 --port 3017، وافتح http://127.0.0.1:3017 وأدخل رمز البيئة نفسها.
4. للبناء: npm run typecheck، ثم npm run lint، ثم npm test، ثم npm run build. اختبارات Windows: python -m unittest discover -s tests من windows.
معاينة 127.0.0.1 خاصة بهذا الكمبيوتر؛ ليست عنوانًا يفتحه الهاتف مباشرة.

تهيئة Neon وVercel بعد الموافقة على النشر
Vercel لا يصل مباشرة إلى عنوان Tailscale الخاص. يستخدم الاتصال الخارجي عاملًا على Windows يطلب المهام من الخارج؛ لا يلزم فتح منفذ عام على الكمبيوتر. الطلبات والردود في طابور Neon مشفرة بـAES-256-GCM مع ربط التشفير بمعرّف المهمة والاتجاه.
web/db/relay.sql يهيئ طابور النقل وحد محاولات الربط. الطلب ينتهي بعد خمس دقائق؛ لا يُعاد إسناد المهمة المستلمة. تُحذف صفوف النقل عند الاكتمال أو تنظيف المنتهي، وتُرفض المهام المنتهية حتى إذا أُعيد إرسالها. سجل العامل يحتفظ بالرد المشفّر حتى انتهاء الطلب فقط. هذه البيانات المؤقتة منفصلة عن الذاكرة الاختيارية.
النشر يحتاج DATABASE_URL ومفتاح جلسة ومفتاح نقل AES منفصل ورمز عامل منفصل ومعرّف تركيب واحد، كلها في أسرار الخادم. لا تُرسل هذه المفاتيح إلى JavaScript المتصفح. اضبط WASLA_WEB_ORIGIN إلى رابط النشر الحقيقي، وWASLA_TRANSPORT=relay. الحد الأقصى لمدة الوظيفة ٣٠٠ ثانية؛ يجب أن تدعم خطة الاستضافة ذلك. يستخدم الطابور استعلامات دورية لها تكلفة تشغيل؛ لم يُعلن تقدير مالي دون قياس الاستخدام الفعلي.
على Windows: WASLA_RELAY_ENABLED=1، وWASLA_RELAY_URL إلى أصل HTTPS للنشر، وWASLA_RELAY_TOKEN، وWASLA_RELAY_INSTALLATION_ID، وWASLA_RELAY_KEY_BASE64، وWASLA_RELAY_LOCAL_URL، وWASLA_RELAY_LOCAL_PIN. شغّل python -m wasla.relay صراحة. لا يعمل العامل تلقائيًا عند بدء Windows. لا يمرر سطح المكتب أو الصور عبر هذا الطابور.
لتخزين المعرفة على Neon بدل SQLite، ثبّت windows/requirements-hybrid.txt في بيئة التشغيل واضبط WASLA_DATABASE_URL. يتطلب الاتصال verify-full. لا توجد هجرة تلقائية للمعرفة الموجودة؛ يجب اختيار نقلها صراحة قبل تبديل المخزن.

المعالجة السحابية الاختيارية
OpenAI Responses API وweb_search جاهزان كخيار، ومغلقان حاليًا. لم يُستخدم مفتاح مدفوع أو تُجرَ مكالمة OpenAI مدفوعة في الاختبار. يبقى Qwen هو الافتراضي.
التفعيل يتطلب OPENAI_API_KEY وWASLA_CLOUD_ENABLED=1 وWASLA_CLOUD_MODEL، وحدًا يوميًا WASLA_CLOUD_DAILY_BUDGET_USD، وأسعار النموذج الحالية WASLA_CLOUD_INPUT_USD_PER_MILLION وWASLA_CLOUD_OUTPUT_USD_PER_MILLION وWASLA_CLOUD_SEARCH_USD_PER_CALL، وحد سياق محافظ WASLA_CLOUD_CONTEXT_TOKEN_LIMIT. لا توجد أسعار أو أسماء نماذج مدفوعة مفترضة.
كل طلب يحتاج اختيار السماح بالسحابة. وضع «محلي» لا يرسل إلى OpenAI. تستخدم الطلبات store:false ولا تُعاد تلقائيًا عند غموض النتيجة. يُحجز تقدير محافظ قبل الطلب ويظل محسوبًا حتى عند انقطاع الرد؛ هذا حد تطبيق على الحجوزات وليس ضمان فاتورة المزود. تظل تكلفة البحث الإجمالية «غير معروفة» عندما لا تكفي بيانات الاستخدام لحسابها.

نتائج التحقق — ٢ نوفمبر ٢٠٢٦
أُعيد تشغيل مجموعة اختبارات Windows كاملة بعد إصلاح البحث العربي باسم منتج واحد: نجحت الاختبارات الـ٢٠٨ خلال 11.833 ثانية، بأمر python -m unittest discover -s tests -q من مجلد windows. تستخدم اختبارات الخادم حالة مؤقتة وخدمات وسطح مكتب بديلة؛ تشغيل التطبيقات والنقل الخارجي في هذه المجموعة محاكيان. لم يُرسل إدخال فعلي للفأرة أو لوحة المفاتيح، ولم تتغير خدمة الهاتف أو حالتها.
نجحت فحوص الويب السابقة: TypeScript عبر npm run typecheck، والتدقيق عبر npm run lint، واختبارات الويب الـ١١ عبر npm test، وبناء الإنتاج عبر npm run build.
نجحت أيضًا فحوص تكامل منفصلة على Neon الحقيقي، وعينة دورة طلب ورد مشفّر بين وسيط النقل وعامل Windows وخدمة الاختبار المحلية مع التحقق من شهادة TLS وبصمتها. زمن عينة فحص Neon كان 2278 ملي ثانية، ودورة النقل المشفّر 1189 ملي ثانية. هذه نتائج بيئة الاختبار؛ لا تعني نشر الموقع علنًا أو قياس اتصال الهاتف عبر الإنترنت.
استغرقت عينات الحساب واسترجاع المعرفة نحو ١٠ ملي ثانية. استغرقت عينة إجابة طويلة من Qwen نحو 33.58 ثانية؛ هدف الأربع ثوانٍ لم يتحقق لهذا النوع من الإجابات. الأرقام عينات محددة وليست ضمانًا لكل طلب، ويتغير الزمن بطول الإجابة وحمل الكمبيوتر والشبكة.
تحققنا من الواجهة الفعلية في Chrome: تبديل العربية والإنجليزية، والحفظ الاختياري ثم إعادة فتح المحادثة، واسترجاع المعرفة، والحساب، والبحث. أعاد السؤال «ابحث عن وثائق Tailscale الرسمية» ثلاثة روابط مرتبطة بالموضوع خلال نحو 643 ملي ثانية بعد إصلاح الاستعلام المختلط. النتيجة مقتطفات وروابط بأدلة محدودة، وليست مراجعة كاملة لمحتوى الصفحات. عرض الهاتف عند 360 بكسل خالٍ من التمرير الأفقي.
