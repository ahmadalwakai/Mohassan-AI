# Mohassan AI — تطبيق أندرويد

تطبيق أندرويد أصلي بـ Kotlin وJetpack Compose. يتصل بخادم موحسن عبر `https://www.mohassansy.com` ويستخدم واجهات الحساب والمحادثة نفسها التي يستخدمها الويب. اسم التطبيق «Mohassan AI»، ومعرّفه `com.ahmadalwakai.wasla`. الواجهة عربية ومن اليمين إلى اليسار.

## الاستخدام

1. افتح التطبيق وسجّل الدخول بالبريد الإلكتروني وكلمة المرور لحساب موحسن. يحفظ الهاتف كوكي الجلسة مشفرًا بمفتاح في Android Keystore. إذا انتهت الجلسة، يعرض التطبيق شاشة الدخول. يمكن إنهاء الجلسة من إعدادات الحساب.
2. ابدأ محادثة أو افتح محادثة سابقة. تظهر الرسائل وتحديثات العمل وبطاقات الأسئلة والموافقات والخطوات الآمنة أثناء عرض المحادثة. يمكنك إرفاق ما يصل إلى أربع صور إذا أتاحها الخادم، وتقييم الرد، وعرض لقطة متصفح موحسن عند توفرها. إذا ضاع رد الخادم وكان يدعم مفاتيح منع التكرار، يعيد التطبيق الطلب بنفس المفتاح والمحتوى. يمكن التحقق من الطلب غير المؤكد أو إعادته في غضون ١٢ ساعة.
3. للتحكم في Windows، افتح شاشة الكمبيوتر. إذا لم يكن لديك كمبيوتر مرتبط بحسابك، أنشئ رمز الربط وألصقه في Mohassan Companion خلال دقيقتين. اختر النافذة وامنح إذن المشاهدة والإدخال محليًا في Companion.
4. شغّل «التحكم عن بُعد بتطبيق Windows» للحصول على إذن تحكم مدته ١٢٠ ثانية. يتحقق التطبيق كل ١٥ ثانية من الإذن ويجدّده عندما يتبقى أقل من ٣٥ ثانية ما دام التطبيق في المقدمة. تصل الصور كل نحو ٠٫٩ ثانية أثناء فتح شاشة التحكم. يبدّل إطفاء المفتاح إذن التحكم بإذن مشاهدة مدته ٣٠ ثانية. ينهي «إيقاف كامل» المشاهدة والتحكم، ويلزم إذن محلي جديد لاستئنافهما.

تسجيل الدخول والمحادثة يعملان عن طريق الخادم السحابي. ربط الكمبيوتر مطلوب للتحكم في Windows فقط. كل طلب يغيّر حالة الخادم يرسل ترويسة `Origin`، ويُرسل كوكي الجلسة دون تعديل. يستخدم التطبيق شهادات HTTPS الموثوقة في Android ويرفض إعادة التوجيه.

## البناء والاختبارات

يتطلب البناء JDK 17 أو أحدث وAndroid SDK لمنصة API 35. الحد الأدنى لتشغيل التطبيق هو API 26.

```sh
cd apps/android
./gradlew testDebugUnitTest assembleDebug
```

ملف التثبيت الناتج هو `app/build/outputs/apk/debug/app-debug.apk`. تقرأ اختبارات JVM التبادلات الـ٥٢ في `tests/fixtures/cloud-phone` وتغطي أشكال الطلبات والردود، وإعادة الإرسال، وانتهاء الجلسة، وتوقيت أذونات Windows. التشغيل مع حساب حقيقي وكمبيوتر مصرح له يحتاج اختبارًا على جهاز Android مع المالك.
