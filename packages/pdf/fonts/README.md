# خطوط المستندات

ضع هنا ملفات خط عربي مفتوح الترخيص (`.ttf` أو `.otf` أو `.woff2`)، مثل Noto Naskh Arabic أو Cairo،
فتُضمَّن في كل ملف PDF تحت الاسم «Mohassan Document» ولا يعود الإخراج معتمدًا على خطوط الجهاز.
الملف الذي يحمل في اسمه `Bold` يُستخدم للوزن 700. المجلد فارغ افتراضيًا: على Windows يستخدم Chromium
خط Segoe UI أو Tahoma للعربية.
